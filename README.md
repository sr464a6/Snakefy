> **Snakefy** is a modern recreation of the classic Snake arcade game built with **Python** and **Pygame**. Players control a growing neon snake, collect pulsing food items, unlock achievements, and avoid collisions while aiming for the highest score possible.

---

## 🎮 Controls

<div align="center">

| Key | Action |
| :---: | :--- |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | Move Snake (Up, Down, Left, Right) |
| <kbd>Space</kbd> | Start Game |
| <kbd>R</kbd> | Restart Game after Game Over |

</div>
